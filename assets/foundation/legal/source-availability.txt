LGPL components

FFmpeg has been rebuilt from official n8.0.1 source commit 894da5ca7d742e4429ffb2af534fcda0103ef593 (annotated signed tag object d22ecc4f6f3fca77b3e71b18641ceddb25973e97). The release archive generates the version label 8.0.1; the former prebuilt used git tag label n8.0.1. The two inherited patches are the Opus libm configure check, rebased without changing its one-line effect, and the unchanged pinned atempo.patch. All four ABIs preserve the existing configuration, public symbols, dependencies and public headers except this generated version label. Codec/protocol registries, representative decode output and runtime tempo behaviour were compared against the old binaries before replacement.

Corresponding source, recipes and provenance:

See .github/build/ffmpeg-foundation.lock.json, .github/build/ffmpeg-opus-n8.0.1.patch, .github/build/build-foundation-ffmpeg.py and docs/foundation/FFMPEG_REBUILD.md. The unchanged atempo patch is pinned by hash and the ffmpeg-android-builder revision in nova-ci.xml. The protected build produces a companion corresponding-source archive containing the patched complete FFmpeg source and actual configuration. Source downloads and the exact NDK 30.0.14904198-beta1 toolchain are pinned by SHA-256. Existing external codec/crypto libraries are retained; their sources and individual licences remain available in this catalogue and the manifest. OpenSSL static module source is openssl-3.5.7 commit 8cf17aaeb4599f8af87fefd810b5b5fee90fe69e; its complete upstream source archive URL/hash is in the lock and companion source archive metadata.
