FFmpeg 9.0.2 source commit 946fcce07b6dcd0331c8cc609192aeff5e1924f8 is rebuilt for arm64-v8a, armeabi-v7a, x86 and x86_64 at API23. The configuration disables GPL, version3 and nonfree components; the selected library licence remains LGPL-2.1-or-later. The reviewed Opus detection, audio-tempo media-frontier and libmysofa compatibility patches accompany the recipes. Native TLS certificate and hostname checks stay enabled. OpenSSL4.1 is built from source under Apache-2.0. libass and all linked font/text dependencies have their own full notices in this catalogue.

FFmpeg is dynamically linked. FriBidi, selected font dependencies and OpenSSL are statically linked into the player; AudioCompress and portions of the native player have LGPL terms. Their complete source, applied patches, generated FFmpeg configuration and build instructions are retained with the corresponding-source package. Rebuild the modified native stack and JNI wrappers, then build the application from source with those libraries. This permits modification and relinking; installation of a modified APK on Android requires a developer signing key, or an authorized build with the existing installation certificate. The private installation key is not part of corresponding source. No restriction on reverse engineering for debugging modifications to LGPL libraries is imposed by this application.
