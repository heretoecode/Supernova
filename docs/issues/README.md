# GitHub Issues — source files

The Issues on GitHub were created from these files on 5 November 2026. GitHub is the live copy: update an issue there
when its status changes, and add any new one here too so the record survives.

- `ISSUES.json` — every issue with its GitHub number, labels and milestone. Tracker **#31** holds the 46 release items
  of 0.156 (#32–#77) as sub-issues; #78–#102 are parked ideas (`parked`) and open questions (`decision-needed`).
- `LABELS.json` — the 13 labels with colours and descriptions.
- `MILESTONES.json` — milestone `0.156` (GitHub milestone number 1).

Close a release item when it is in a signed build that the owner has checked on the Shield.
