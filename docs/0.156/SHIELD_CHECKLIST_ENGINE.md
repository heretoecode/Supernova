# 0.156 — checks on the Shield

1. Play a Put.io film, pause for three minutes, then carry on: the picture stays clear and speech stays in time.
2. Seek forwards and backwards in a large 4K Put.io film: preview pictures appear without interrupting playback.
3. Put a subtitled film in picture in picture: subtitles disappear there and return when you press OK to go full
   screen.
4. Reopen Supernova while picture in picture is showing: the same film returns full screen at the same point.
5. In Library Health, use Find it again for a moved file: the correct file opens and its watched state and saved place
   remain.
6. Test an unsaved SMB connection: the folder and video counts are correct, and a wrong password gives a clear reason.
7. Test an unsaved SFTP connection: the folder and video counts are correct, and a wrong folder gives a clear reason.
8. Test an unsaved FTPS connection: the counts are correct, and an untrusted certificate is refused with a clear
   reason.
9. Export .nfo files to a writable share: the count advances, the files arrive beside the videos, and the final totals
   agree.
10. Stop an export part-way through, then run it again: it stops promptly, leaves no half-written file and can finish
   normally.
11. Scan both library sources, send Supernova to the background and reopen it: the scan finishes or gives a reason;
   Stop works and a fresh scan can start.
12. Back up the full library, then preview that backup: all expected titles are counted and the previous backup
   remains usable if a new attempt fails.
13. Hide the next episode and let the current one end: playback skips the hidden file, including when repeating a
   folder.
14. Open a title's saved ratings without a network connection: the saved values remain; reconnecting within a week
   does not fetch them again.
15. Export diagnostics after these checks: it opens normally and includes the scan results, playback reconnection and
   any failures with reasons.
