# Owner's review of 0.158.11 / 0.158.12 on the Shield (27 Nov 2026)

The owner's second pass, after the refined pages were built (photos on 27 Nov, local time about 12:00–13:15). Each
note: what was seen, then the decision (owner's words where given, else Claude's recommendation, marked). Every item
is in `BRIEF_0158_C.md` item 13. Numbers P1–P26.

## Crashes and stale files (fix first)
- **P1. Supernova crashes when playing.** MobLand S2 E10 (Preparing playback, then a black screen, then the app
  restarts; twice, about 11:59). Mr. Robot's Resume does the same. A file that can't be opened must never crash the
  app: the player says why in words ("This file is no longer on Seedbox") and returns to Details.
- **P2. Reconnecting a server leaves stale copies (the cause, owner's diagnosis).** The owner reconnected the SFTP
  server a few times; each reconnection added the same files again. The Death of Robin Hood now offers three versions,
  two pointing at connections that no longer exist (black screen, then a crash); only one plays. **Decision:**
  re-adding or reconnecting the same server must re-link the library to it, never add duplicate copies; copies whose
  connection is gone are flagged at once in Library Care › Missing files ("Its connection was removed") with Find it
  again · Remove; the scan record says so.
- **P3. Versions for TV episodes.** Movies offer "choose a version"; episodes don't, so an episode with a stale copy
  just fails. Episodes get the same version choice as movies (same menu), and an unavailable version is never offered
  as playable (greyed, saying why).
- **P4. MobLand S2 E9 still listed; Delete says "Couldn't delete the file".** The file is gone from the server. Most
  likely the episode points at a removed connection (P2), which M2 treats as "server unreachable", a failure. With P2
  fixed it shows as missing; Delete on a file whose connection is gone removes it from the library and says so.
- **P5. Missing files never flags anything, and the row is information only.** Make the row always focusable: with
  items it opens the list; with none, OK runs **Check now** in the row ("Checking… · Done · none missing"). The stale
  copies (P2) and MobLand S2 E9 must appear there.
- **P6. Wrong matches nobody flags.** "Only Fools and Horses - S01E05 - A Slow Bus to Chingford.mp4" is matched as
  Surfside 6 (1960); "Only Fools and Horses - S03E03 - Friday the 14th.mp4" as Step by Step. The file name names the
  show plainly. **Decision:** (a) find out why (diagnostics already record how each match was made: file name, folder,
  .nfo, hash; the report must say which led here) and fix the matcher; (b) a sanity check after every match: if the
  show or film name parsed from the file or folder doesn't resemble the matched title, the title goes to Library Care
  › Not matched with the best guess ("Looks like Only Fools and Horses · S1 E5"); (c) Check matches compares every
  title with its file names the same way and lists the mismatches for review.
