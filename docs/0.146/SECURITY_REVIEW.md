# 0.146 security disposition

The candidate retains `app.supernova.player`, API23, private providers, the existing installation-certificate pin and the0.145 library/credential protections. No signing protection was changed, no key was read, and no public release or main merge occurred.

The final runtime inventory has139 exact resolved archives/POMs, independently checked against CI40846173069. The offline catalogue contains64 complete legal entries. Matching source-built Jetty artifacts have explicit source/patch/optional-feature markers. Sentry8.61.1 families are aligned, rather than mixing Java SDK8.53 with newer Android modules; stable NOVA browser/core/fragment/OkHttp/BC families are integrated. Runtime coordinates, hashes, POM licences and source notices are recorded in the SBOM.

The full OSV query covers all139 runtime coordinates plus six explicit fork-lineage queries. Four Jetty upstream-version findings remain visible; the reviewed source backports address the reproduced code paths. The same query no longer returns eight of the nine legacy9.2.30 findings. The remaining legacy authority finding and three newer parser/authority/Digest findings have specific patches, original-version negative controls,22 host integration cases and28 actual Android23 transport/trust/FTPS cases. See JETTY_SECURITY_BACKPORT_REVIEW.md. No version relabel or advisory suppression claims a clean upstream package.

The exact15 native source commits were queried separately. Eleven findings were identified, including notices published28October. FFmpeg, FreeType and zlib received the reviewed upstream backports described in NATIVE_SECURITY_BACKPORT_REVIEW.md. FFmpeg's libssh SFTP backend is unbuilt; application SFTP retains its known-host/first-use identity policy. Unneeded libxml2 XInclude/XPointer/HTML/output features are disabled, and their affected feature symbols are absent from the actual player DSOs. Those source-version findings are retained with feature/reachability evidence; they are not described as global library fixes.

FFmpeg peer and hostname verification default on, including nested HLS requests. OpenSSL uses an app-private system-plus-bundled CA bundle. Java TLS uses per-connection configuration without a process-global trust manager/verifier replacement. The old API<=25 TrustAll implementation is removed. Trusted HTTPS succeeds; untrusted/wrong-host HTTPS and wrong-host nested HLS requests fail on each ABI. NativeTrustRoots executes successfully on the actual Android23 framework.

Native JNI/subtitle lifecycle and concurrency have13 ASan/UBSan and seven TSan host cases plus180 arithmetic/sync regressions. The new component security regressions independently reproduce six failures in the original code and pass all six patched cases under ASan/UBSan. These are scoped software results. They do not prove absence of all vulnerabilities, memory leaks, GPU defects or real-provider incompatibilities.

Real NAS/UPnP servers, IPv6 LAN interfaces, Shield HDMI/ARC/SPDIF/private-listening chains, physical GL subtitle presentation and signed upgrade/rollback remain device QA. The malformed CID exploit font was not available, so that patch has source/build/rasterization evidence but no independent exploit-font reproduction. The retired experimental FFmpeg Sonic codec was investigated against the actual0.145 DSOs: a valid sample is rejected without experimental strictness on every ABI; AVOS does not enable that mode. This is separate from the supported Sonic PCM speed backend. Details and a concrete optional-port path are in SONIC_CODEC_RETIREMENT_REVIEW.json.

The final lint review additionally identified the actual Java FTPS permissive-default path. FTPS_TLS_REVIEW.md documents CA-chain and original-host verification on control/data channels, failure cleanup, original-default negative control and the API23 compatibility investigation. Untrusted/self-signed peers fail rather than receiving an accept-all exception.

PlayerService exposes a local Binder and is started/bound internally; MediaRetrieverService’s AIDL client is the same application’s scanner process. Both services are now explicitly non-exported, preserving same-UID cross-process use while rejecting unrelated applications. The final APK recorder verifies their actual merged manifest flags. The deliberately exported Android TV search provider remains a fixed-projection read-only system integration; arbitrary query projection/selection and mutation APIs are not exposed. Cleartext remains available for explicitly configured local HTTP/WebDAV/UPnP providers. Neither choice is described as eliminating every IPC/plaintext risk.
