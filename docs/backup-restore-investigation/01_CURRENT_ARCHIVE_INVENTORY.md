# Current format 1.0 archive inventory

All entry rules below are **source-verified**; actual presence/size in the owner's file is unknown. `addFileToZip` streams entire file bytes in 8 KiB buffers; no separate folder records are emitted. All DB copies go through `BackupPrivacy.database`: copy, null secret-named columns, sanitize text containing URLs, VACUUM; viewing selection can perform another VACUUM. This copies **all tables, fields, views, indexes and triggers already present**, including unforeseen historic objects. It is not a selected-table export. Every field's representation is SQLite storage as defined in the field matrix. Numeric codec/duration/size/dates are parsed/scanned metadata; `*_id`, foreign-key columns, type and source IDs are relationships; text labels/titles/names/plots/genres/languages are metadata or user strings; `*_file`, `_data`, path/source columns are location references; `bookmark`, watched/resume/date fields are viewing state; `Archos_playerParams`, subtitle delay/ratio, favourite track and hidden flags are per-file customisation; counters/work state are internal. Origin/purpose in the table above applies to each field in that row; specific viewing filtering is recorded per affected field. Generic URL sanitization keeps filenames/host/path and drops user-info/query/fragment; raw labels are not a proof of secret-free data.

All current views/indexes/triggers are inside the DB file. [SQL source catalog](evidence/sql-source-definitions.json) records definitions, including historical variants; it is **not** a claim that every historical object is simultaneously active. Views calculate derived projections/joins, indexes accelerate lookups, triggers forward scan rows, enforce relationship/cleanup behaviours. They have no independent backup switch. Exact live SQLite object inventory/extra user-created fields is unavailable without private artifact inspection.

## Explicit exclusions and size limits

Excluded writer content: `credentials_db`, `ftp_shortcuts_db`, blacklist DB, put.io token/Keystore material, OpenSubtitles/Trakt secrets, host trust, OS SAF grants, media video/audio files, physical subtitle/NFO files, episode-still files, diagnostics, enrichment jobs, general people/discovery/title-logo/technical/subtitle-search caches and named preferences outside the three-group whitelist. Credentials are checkpointed by `flushDatabaseWAL` but never passed to ZIP writer. Unused legacy `cleanupExistingData`/`addDirectoryToZip` methods do not define the active import/export pipeline.

No per-entry measured bytes available. Owner-observed total **16.87 MB** and artwork **~5.5 MB/~40 images**, including 25 posters/~2.3 MB and backdrops/~3 MB, are estimates, not a verified compressed/uncompressed split. Cannot promise a 5.5 MB ZIP reduction. Source bytes/field counts are not device archive sizes. Future private inspection should record safe aggregate counts and compressed/uncompressed totals only; never publish filenames, personal records or image contents.
