# 0.140 target-device acceptance checklist

All device checks below are **NOT RUN** in this execution environment. Software tests, native decode fixtures, signed binary checks and Drive readback are recorded separately. Do not convert these rows to PASS without observing the target device. Record device/OS, display mode, APK SHA-256, source commit, test media/source and actual result; attach redacted diagnostics and screenshots where relevant.

| Check | Expected observation | Status |
|---|---|---|
