## Visibility and dependencies

`CustomApplication.onCreate` currently enables `try_new_ui` only when absent; `MainFragment` selects TopNavigation when that preference is true. Fresh Foundation defaults are true, so the flag does not explain the missing carousel within the approved new UI. A restored/stored false value remains a separate risk with no visible toggle to correct it. The correction will enforce the approved Foundation UI policy without exposing the obsolete toggle or changing other preferences.

The carousel requires the reference card component, its More Info action background, viewport-sized Home HERO binding, Home global-artwork clearing, the existing left/right and Details actions, and rail clearance for focus enlargement. It uses existing candidate selection, official title artwork, Picasso request lifecycle and Details callback. Movies/TV global artwork and existing library/network semantics must remain intact. Foundation double-ring scan status is in TopNavigation and is independent of the replaced legacy HERO indicators.
