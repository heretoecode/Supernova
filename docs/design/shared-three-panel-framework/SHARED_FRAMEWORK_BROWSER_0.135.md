# Supernova 0.135 — Shared Three-Panel Foundation and Universal Browser
**Authority:** User-approved design discussion through 2026-10-10. **Status:** Codex implementation handover, not yet implemented. This is the authoritative later decision over earlier mockups/notes where they differ. Preserve existing app identity, signing, installed 0.134 baseline and unrelated working behaviour.

## One foundation, one browser
Create reusable three-panel foundation shared by Settings and Network & Files, with consistent geometry, typography, shadows, headings, icons, row focus and layout. Create ONE actual file/folder browser implementation, not separate Home and Network & Files copies. Full-page Network & Files = 100% footprint; empty-library Home = approximately 60–65% footprint (start at 65% and validate on Shield), preserving same feature set, typography, icon sizes, D-pad targets, file operations, breadcrumb and selection logic; reduce container footprint and visible rows, not scale text smaller. Browser must be the same source of truth and fixes/features apply everywhere. Codex must audit ALL existing browser/picker entry points in code (activities, fragments, folder/source selectors, network and local storage, any other file browsers) and replace with shared browser where semantically appropriate, documenting exceptions. No assumption that only Home and Network & Files use old browser.

## Visual foundation — provisional sizing to test on Shield
Left/centre/right usable widths ~24%/38%/38%; equal height, ~16dp interpanel gaps, 20–24dp inner padding, 14–18dp corner radius. Existing Supernova font; headings ~20–22sp, option labels ~17–19sp, descriptions ~15–16sp, parent rows ~48–52dp, child rows ~42–48dp, icons ~20–24dp. Consistent heading inset, subtle divider, breathing room before first row; fixed label/value alignment and reserved space for status so layout doesn't jump. Icons monochrome, provider icons monochrome, country flags colour. Space Black Blend, restrained translucent panels, soft diffused neutral edge shadows and subtle white top/edge highlight (Home hero-inspired depth); no aggressive glow/blur. Row-only white focus outline; no active-panel glow. Top navigation is retained in app; absence in Settings/Subtitles reference image is only illustrative. Remove scroll-dependent navigation blur/frost/fade from Network & Files, Settings, Search, retain on Home, Movies, TV; allowlist preferred.

## Three-panel D-pad focus
Top navigation changes pages on OK only, not on focus. On entering Network & Files, focus Overview, topmost selectable left item. Up from Overview returns to Network & Files top navigation. Left Up/Down moves among left items; centre and right auto-load on focused entry without OK. Expandable parent opens on OK, not focus; one expanded at once, children indented, parent focus stays then Down enters child; keep all parents visible, if needed compress vertical gaps without shrinking text/icons, smooth ~200–250ms. Right from left goes to first selectable centre control. Centre Up/Down stays centre. Left from main vertical centre list returns to exactly remembered left item. Horizontal toolbar/breadcrumb groups consume Left/Right within group; at edges, panel transition can occur. Right from selected centre file/folder goes straight to first actionable right-panel row (information is not focusable); if no action, don't enter empty panel. Right Up/Down stays among actions; Left returns to exact centre item and scroll. No focus disappearance, jump or panel blanking. Back navigates folder ancestry first, then browser exit if appropriate.

## Browser structure
LEFT: Overview, internal/USB devices, network shares, Saved Locations, contextual source/scan/Library Health sections. Every actionable row has aligned monochrome icon.
CENTRE: top evenly spaced inset pill controls (1) List/Grid, preserving selection and scroll; (2) Sort, compact contextual popup with existing working choices; (3) All Files ON/OFF switch, existing Supernova accent on, neutral off, white thumb. ON all file types, OFF supported video only; folders always shown. Same persisted setting, instant two-way sync with Settings > Library & Metadata > Display All Files in Browser. Below controls: SINGLE-LINE horizontally focus-scrollable breadcrumb carousel, Home-row-like movement, all ancestors reachable, no wrap/ellipsis/hiding intermediate segments, natural widths, OK navigates to ancestor. Below: files/folders in list/grid. OK folder opens it; no right-panel redundant Open. No flashing during folder changes. Use existing animated Supernova loading symbol from Preparing Playback / Home scan pill, not spinner. No bottom remote-control legend.
RIGHT: structured fixed Name, Type, Address, Library status; actual available media technical details (size, container, duration, resolution, video/audio codecs/channels), async fetch without invented values; long paths wrap/scroll inside value region, labels fixed. No separate View Details for unindexed files. First actionable row on Right; folder actions Add to Library and Save Location, state-aware management/remove/exclude; file-appropriate actions. Replace legacy Source Options popup with in-panel actions.

## Inclusion/exclusion and scan
Adding a parent includes descendant media recursively, auto-detect Movies/TV, no extra classification popup. Allow exclusion of individual child folders/files while keeping parent monitored, even if all current children excluded, so future nonexcluded additions are discoverable. Exclusions persist across scans. Avoid nested source duplicates. Stage add/remove/exclude changes; no scan until Apply & Scan. When user actually attempts to leave browser (top nav, Back exiting browser, switching away from browser section) with pending changes, show centred modal ABOVE browser with same soft depth shadow/edge highlight, lightly dim underlying page, no frosted blur. Fixed heading, clear unsaved/not scanned explanation, scrollable lists grouped Added, Excluded, Removed (distinguish removal of previously indexed items), and actions Discard Changes, Keep Editing, Apply & Scan. Modal traps focus; Keep Editing restores exact focus; no modal on ordinary panel-to-panel focus or Back within folders, and no prompt without changes. Never delete physical files; clearly state library removal affects index only. Apply persists selection and invokes EXISTING scan engine, not duplicate scanning. Preserve existing progress/background scan/cancel/rescan/error functions; regression-test with new selections. Pending changes while scanning must not start overlapping duplicate scans.

## Scan overview, Library Health, source disconnection
Fixed-layout Scan Overview: Status, Last completed scan (human-friendly relative time), Current activity, Sources, Files processed, Added, Updated, Problems, reserved progress indicator; no layout jumps, flashes or raw seconds. Existing scanning lifecycle preserved, not redesigned. Library Health lives in Network & Files within shared foundation, respecting earlier approved Library Health design. Disconnected USB/network and physically missing media remain in library with visible unavailable indicator; retain artwork/metadata, watched state, Continue Watching and resume position keyed to stable media identity/ID tag, not filename alone. Reconnection restores availability automatically on reliable match; do not rebuild library or discard progress. Differentiate offline source vs genuinely missing file, report affected media/sources and recovery in Library Health. No destructive automatic purge.

## Home first launch
Inline welcome message explaining empty library, user free to explore, use compact shared browser below when ready, advanced management in Network & Files. No modal wizard or forced onboarding/Skip button. Same browser functionality. First successful library media addition ends first-time welcome; don't automatically relaunch onboarding merely because library later becomes empty. Preserve D-pad escape to Home nav. Test responsiveness at Shield viewing distance.
