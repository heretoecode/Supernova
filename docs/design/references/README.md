## Standing workflow — all future approved mock-ups

Every user-approved visual mock-up must be uploaded to this folder on `codex/post-4.1.7-shield-fixes` and linked from the relevant `docs/design/*.md` specification and, where appropriate, `docs/design/VISUAL_REFERENCE_MANIFEST.md`. The user may upload under any temporary filename through the GitHub web interface; after upload, the assistant will inspect, rename to a descriptive stable filename (for example `details-information-approved.png`), reconcile written specifications, and mark the reference approved. **Do not treat an image as uploaded before it actually exists in GitHub.** Do not modify production code or merge branches merely to store design references. For the current Details design, the approved image must reflect the final refinements: headings CAST/CREW without counts and equal, increased row spacing; a pre-refinement image is provisional until corrected.
