## Implementation workstreams (all required)
1. **Playback HUD + Settings:** cinematic minimal transport; left play/pause, slim seek line, accurate conditional chapters/tooltip, remaining/finish time on right, no duplicate elapsed time. One right-hand dark translucent Settings panel with exactly four **horizontal top tabs: Subtitles | Audio | Display | Playback** (Subtitles first). Group *real, code-supported* options based on audit; preserve subtitle/audio workflows, persistence, accessibility, Back/focus, playback and diagnostics. Remove Technical Information and Report a Problem **from playback UI only**. Address verified audit bugs. No unsupported fictitious controls; online chapter fetching is not approved.
2. **Home hero:** fix overlapping/misaligned cards after rapid left-right reversals; improve scrolling smoothness and focus responsiveness without changing the visual design.
3. **Open-source licences:** replace *all* paginated licence viewers with a compliant, TV-friendly disclosure; verify dependency attributions and retain legally required texts/notices.
4. **Global language labels:** display region-specific flags only when a reliable region exists; otherwise a neutral language/globe icon. Centralise mapping; cover audio, subtitles, metadata, preferences, search and other language lists.
5. **Library Statistics:** vertically centre values consistently and increase entire panel opacity to match adjacent Sort Air Date / Newest First / List View controls.
6. **Shared TV keyboard:** single-line-height input; dedicated `.`, `,`, `/`, `\\` keys; **retain original bottom-left Caps Lock**, not Shift; retain Space, Backspace, Clear, Done, Cancel and D-pad focus. Exploratory keyboard mock-up was **not approved**.
7. **Put.io sign-in blocker:** repair Connect Put.io initial/follow-up focus so it does not jump to Home and trap the user in Cloud Services; ensure all authorisation controls are accessible and Back/re-entry work. **Release-blocking for Put.io acceptance**; do not claim successful real login without account-based test.
8. **Third Library page toolbar:** keep sort/view controls left; pin **Edit Library** to the far right on the same toolbar, preserving styling and remote access.
9. **All Library pages:** vertically centre the row containing the focused item in the **library content viewport**, smoothly on navigation and after stopping; handle first/last/short rows and fast D-pad repeats without focus loss or jitter.
10. **Movie/TV Details:** lower the tab bar below the main Details card, with clear visual separation (~20–24 dp starting QA target); preserve both surfaces' existing borders and functionality.
