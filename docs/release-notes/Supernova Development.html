Supernova 0.137

QA · Delivered for testing

11 October 2026 · Reliability and responsive interface QA · Version code 137 · Source release notes · Signed QA APK

✨ New and expanded features

  • Added an empty-library Home experience with hero and Recently Added placeholders, plus a welcome screen using the Supernova icon. These are interface placeholders, not fake media; Recently Added still respects its saved Hidden setting.
  • The welcome screen opens the existing Network & Files flow without starting a scan, or lets you explore Home. Explicit dismissal is remembered after restart.
  • Enabled the highest supported bounded diagnostic detail by default and removed the detail-level selector. Existing logging opt-out, redaction, retention limits and report export remain supported.

🎨 Interface and navigation

  • Introduced shared responsive layout dimensions, adaptive poster grids and scrollable navigation, toolbars and panels to keep remote-control actions reachable.
  • Refined information and confirmation dialogs with bounded widths, scrolling content, consistent buttons and focus returning to the opener.
  • Improved Page Name entry with a centred heading, hint and caret. The shared keyboard starts at T and offers Caps, Space, Backspace, Clear, Done and Cancel; Done commits the field, while Cancel rolls back the edit.
  • Fixed custom-library wizard navigation: Up from Step 1 reaches global navigation and Right from Review reaches Save. Unsaved changes default to Continue Editing; Save validates and opens the page, while Discard returns Home.
  • Aligned custom-library toolbars, command icons and whole-card focus styling with built-in pages, with Edit positioned at the right.
  • Prepared three complete hero cards around the active item, with bounded artwork and logo warming, stable typography during transitions and retrying cancelled cold artwork requests. Refined transitions and the darker More Info button; the casual font is limited to taglines. Final smoothness and visual fidelity still need physical SHIELD verification.

🛠️ Fixes and everyday improvements

  • Fixed the reproduced Settings switch-layout crash in Integrations. Automated navigation reaches all 12 categories, including Advanced Diagnostics and report export.
  • Changed native importer paging so a full batch of excluded rows cannot keep repeating and starve included files on another drive. The regression advances past 2,500 excluded records without deleting records. Quiet importer status now reports a lack of recent progress without falsely declaring success or failure; real multi-drive indexing remains user QA.
  • Refreshes Home after viewing-history writes commit, addressing the stale Continue Watching snapshot on return from playback. Existing resume, completion, visibility and Home deduplication rules are preserved.
  • Removed automatic Continue Watching row insertion from built-in TV Shows and Movies pages; Home remains its location and saved progress is retained.
  • Improved Network & Files navigation beyond the visible viewport in both list and grid views. Refreshing after the focused row disappears keeps a nearby item focused; an empty directory retains its path and a reachable control instead of clearing the listing during layout.
  • Fixed All Files filtering so On includes unsupported and hidden files and folders, while Off restores supported-file filtering and hides dot files and folders. Toggling retains the current path and browsing preferences without scanning or changing library inclusion.

⚡ Reliability and testing

  • Exact-source automated checks passed: 528 application tests with no failures, errors or skips; 67 Python tooling checks; and release lint with zero errors and 1,496 warnings. These are automated results, not physical SHIELD acceptance.
  • Build conformance checked 138 reviewed dependency hashes, all 88 packaged native libraries and 24 rebuilt FFmpeg libraries. Existing native regression evidence covers 64 decode cases across four ABIs; it does not establish device playback.
  • The signed Supernova_0.137.apk was independently verified as app.supernova.player, version 0.137, version code 137, with the existing signing certificate and the tested unsigned payload. Its Drive copy was downloaded and verified to match.
  • APK source commit: 68caa2c0ac3c42073b8ed2168995c2316625b29a. APK SHA-256: d999db6387ec380de22818d3324c1acf4ffa6d956a3961f594878048644325fe. Successful signed build and verification.
NOT TESTED — USER QA REQUIRED: No physical NVIDIA SHIELD testing or signed upgrade test is claimed. Real external-drive indexing, immediate Continue Watching behaviour on the device, playback, final focus and layout fidelity, font readability and hero frame timing await the 0.137 SHIELD checklist. This is a delivered development/QA build, not a public release.

📌 Still separate from this release

  • Movie and TV Details page redesign and Playback HUD redesign remain deferred.
  • Live put.io authentication and service configuration remain separate; unfinished publisher, Google Cloud OAuth and automated publishing setup were not restarted.

Supernova 0.136

QA · Installed for testing

October 2026 · Refinement release · Verified development release notes

✨ New and expanded features

  • Added a guided five-step process for creating custom library pages, with easier editing and clearer prompts before saving or discarding changes.
  • Added Library Health tools within Network & Files to help identify and manage library or storage problems.
  • Added more useful diagnostic reports, including information that can help investigate crashes, freezes and unusual navigation behaviour.
  • Improved the way watch history is retained, with separate controls for playback progress, clearing history and including history in backups.

🎨 Interface and navigation

  • Refined the Home screen's featured artwork, information layout and More Info button; removed the separate Play action from featured cards.
  • Updated the top navigation with smoother transitions, a moving accent underline and more consistent clock styling.
  • Made Movies, TV Shows and custom library pages more consistent, with clearer filters, genre selection and controls.
  • Redesigned Search around live results, helpful guidance and a consistent on-screen keyboard.
  • Reorganised Settings and Network & Files with more consistent panels, clearer options and remote-control navigation.

🛠️ Fixes and everyday improvements

  • Improved how the Home screen chooses the next unwatched episode while keeping partly watched titles in Continue Watching.
  • Made initial library setup more deliberate: select folders across drives, review your choices and confirm before scanning starts.
  • Improved access to network connections, connected devices and file-browsing controls.
  • Changed licence information so it loads only when opened, rather than doing extra work in the background. The earlier crash cause has not yet been confirmed.

⚡ Reliability and testing

  • Automated build checks passed, including 514 application tests and 58 additional checks.
  • The signed APK was independently checked for package identity, signature and build integrity.
  • Physical SHIELD testing, including playback, focus behaviour and network reliability, remains to be completed.

📌 Still separate from this release

  • Movie and TV Details page redesign and Playback HUD redesign are deferred.
  • Live put.io account authentication still requires final service configuration and end-to-end testing.
