## Consolidated approved scope and corrections
**Foundation/Settings/Network & Files:** Shared 24/38/38 three-panel foundation, font/spacing/depth, focus rules and one universal file browser reused in full Network & Files, ~65% Home first-launch and all appropriate legacy call sites after code audit. Settings left category navigation, centre options, right context/list, right scroll for long text, three-panel consistent focus; Settings About and Release Notes respect earlier design. Remove scroll-dependent top-nav blur on Network & Files, Settings, Search ONLY; preserve Home/Movies/TV. Source and media-folder adding is simplified through browser, including local/USB/network/saved locations. Advanced Diagnostics navigation must fit new Settings framework and retain working diagnostic functionality.

**Library selection/import/health:** Recursively include parent, exclude children/files without unmonitoring parent; stage changes and show shadowed central Added/Excluded/Removed review dialog when exiting browser with pending changes, with Discard, Keep Editing, Apply & Scan. Preserve existing scanner's progress, background execution, cancellation, rescan and error handling; do not replace with speculative new scanning subsystem. Fix confirmed incomplete/unreliable importing via evidence-driven root-cause investigation; do not invent defects. Existing explicit Scan Library command should remain prompt/functional without arbitrary delay. Scan Overview fixed fields and relative last-completed time. Library Health in Network & Files; offline/missing media retains library entries, metadata, ID-linked Continue Watching and watched/resume state; show unavailable status, reconcile on reconnect, never automatically purge or delete physical media.

**Home:** Empty-library welcome and compact browser, Building Your Library, hide Customise until media exists; hero transition dimming/flash fix, remove inherited heavy artwork gradient while retaining readable text; subtle edge/shadow depth on hero; fix focus/zoom frame protrusion and row clipping/continuation, preserve selected-item focus returning from Details/playback; Move/Hide row interaction and Smart Home Rows (Show/Hide independent of dynamic membership, dynamic genre ON/OFF, manual additions, reversible sort). Separate Done action in row customisation with divider and breathing room. Featured should use genuinely available matched items, artwork and synopsis fallback; Resume for partly watched.

**Movies/TV:** Symmetrical page behaviour, Continue Watching on Movies page movie-only, TV Recently Added next-to-watch where multiple episodes added, boxed toolbar Filters/Sort/Order/List-Grid/Columns and custom page Edit at far right only, correct D-pad focus, vertically centre focused poster row, maintain artwork focus zoom and partial adjacent carousel items. Fix filter/divider alignment and navigation regression.

**Search:** Approved local-library-only three-panel mockup, existing keyboard navigation; title/filename/episode, cast/crew/studio/network where indexed, alternate/original titles when verified available; optional articles, punctuation and minor typos. No remote discovery and no unsupported marketing claims.

**Details:** Fix year/runtime/rating metadata alignment; permanent boxes for primary actions, streaming icon/logo behaviour, provider country and season availability where supported without rent/buy; speed up Extras/More Like This/Cast, correct Details/Extras/More Like This tab navigation and return focus, improve Cast & Crew layout and approved expanded-information design. Fix Find a Match keyboard/input focus and poster-bearing results; preserve real metadata matching. No Cast & Crew person profile pages.

**Playback/HUD/subtitles:** Exactly four top-level HUD actions Subtitles, Audio, centred Play/Pause, More; D-pad directions reveal seek bar rather than Up-to-More; no Info or full Settings links on HUD, preserve subtitle/audio functionality in appropriate menus. Fix HUD theme losing colour and diagnostic overlay flash if reproducible; preserve NOVA subtitle appearance/position/sync/downloads/language and improve track labels/flags without unnecessary redesign. Restart Movie/Episode starts at 00:00, including Details More; Remove from Continue Watching Row only removes row membership, not watch state. Up Next 5-second countdown and Play Now, safe binge/credits behaviour; 90% real-viewing threshold (seek-to-end not watched); version selection and compatible quality ranking, accurate file badge and persisted manual choice; Intro/Recap/Outro/Credits/Preview segment skipping policies and source feasibility, no invented IntroDB access.

**Custom Library Page:** One slot after Home/Movies/TV, Create New Page landing, five-step three-panel wizard (details, content type, filters, display, review), preview, edit/rename/delete confirmation, draft protection. Do NOT reintroduce Smart Collections, Discovery Page or sixth Exclusion step.

**Settings/diagnostics/backup/metadata:** Clock matches top nav font/size, restore coloured streaming provider icons in provider selector where user explicitly reported loss (distinguish from monochrome foundation action icons), improve language flags, fix Open Source Licenses freeze/crash. Release Notes latest expanded, older collapsible, semantic icons; avoid unverified version history. Diagnostic Logging OFF offers Keep Existing Logs / Delete Existing Logs / Cancel, secure redaction and bounded capture. Comprehensive backup/restore of nonsecret state, ZIP instructions, validation/staging/rollback, reauthentication; audit and eliminate export of credentials DB or secret-bearing preferences. Metadata reliability/artwork/provider audit, licensing, quota and alternate-title correctness; no speculative ratings integration. Preserve existing app identity/signing.
