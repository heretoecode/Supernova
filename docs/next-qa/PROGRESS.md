Importer investigation: doScan repeatedly queried offset zero. Excluded rows intentionally keep scan_state; 2,500 excluded rows therefore fill the same first page repeatedly. The real private scan method has passed a provider-mocked page regression. Native file retrieval and multiple physical USB volumes remain pending Shield testing.

Home remains the owner of Continue Watching; built-in library rows were removed. Existing Home deduplication, completion rules and visibility preferences are retained.

All Files: the normal filter was already connected. The existing hidden-directory filter ignored All Files and always suppressed dot directories. The browser now holds focus inside the list until a valid replacement is attached, invalidates stale restores, and avoids detached/stale row anchors. The disappearing-row and empty-result case passes in both list and grid modes, with 20 forward and reverse D-pad steps beyond the viewport.
