## Implementation choices
- Stable identity uses TMDb movie IDs or parent-series/season/episode identity; unknown metadata uses exact credential-stripped URI hashing and conservative matching. No filename/title guess creates a next-episode claim. Completion timestamp survives replay; history never expires automatically. Clearing history blocks legacy watched-state re-inference while retaining positive unfinished resume positions.
- First-run setup has an explicit completion flag. Upgrade migration reads actual indexed inventory and retains offline sources; unreadable inventory leaves policy uncommitted. Enumerated drives alone cannot start a scan, metadata enrichment or onboarding dismissal. Lazy provider lifecycle observers register on the main looper.
- Browser width is a stable adaptive 31/42/27 at the standard render size, preserving single-line friendly category names without shrinking text. The documented 24/46/30 was a starting test target. Long paths have a focused value scroll region; information text is clipped inside its scroll viewport. The same browser supplies normal and local-only setup modes.
- Licence focus/Right shows only cheap guidance. Explicit activation reads at most 1 MB on a bounded single-worker queue, with generation/attachment checks and bounded caching. Repeated selection cannot replace the focused section and accidentally trigger another About section. This reduces code risks without claiming the unknown recorded SHIELD crash cause.
- Diagnostic resource/stall/focus classifications are suspected observations, not proven memory leaks or hardware diagnoses. Sampling and exports are bounded and local; credential fields and private source identifiers remain masked. QA defaults to detailed logging, public builds do not.
- Native dependency changes are carried as an explicit patch atop the unchanged pinned 0.135 dependency preparation. Historical release workflows, application ID and certificate pin are preserved. Signing requires exact-source tests/lint/native/binary/payload verification and never substitutes a key.
