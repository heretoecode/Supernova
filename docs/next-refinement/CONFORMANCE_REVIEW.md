- Diagnostic resource/stall/focus classifications are suspected observations, not proven memory leaks or hardware diagnoses. Sampling and exports are bounded and local; credential fields and private source identifiers remain masked. QA defaults to detailed logging, public builds do not.
- Native dependency changes are carried as an explicit patch atop the unchanged pinned 0.135 dependency preparation. Historical release workflows, application ID and certificate pin are preserved. Signing requires exact-source tests/lint/native/binary/payload verification and never substitutes a key.
