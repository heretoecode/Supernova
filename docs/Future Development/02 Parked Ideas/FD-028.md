## TMDb descriptor investigation — 13 October 2026
TMDb's official movie release-date API documents regional release dates and certifications: https://developer.themoviedb.org/reference/movie-release-dates . A published schema representation includes `descriptors` as an array on individual release entries: https://apis.io/json-structure/tmdb/tmdb-api-movie-release-dates-response-structure/ . TMDb's public site translation catalogue also uses a certification `descriptors` label, but that alone is not proof of per-title populated data. **No authenticated, populated real-movie response was verified**, nor reliable coverage for Ireland/UK/US, episodes, localisation or rights. Consequently the field is a promising lead, **not yet a confirmed usable advisory source**. Engineering follow-up: inspect actual provider responses and schema with authorised access, sample real movies and TV series, check regional descriptor values and API terms. Do not ask owner for this technical research; keep FD-028 parked until the owner chooses to revisit it.
