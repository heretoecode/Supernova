## Custom Library five-step editor

| ID / step | Exact controls in production order | Conditions/actions |
|---|---|---|
| WIZ-001 / `1. Page Details` | `Name: <name>` → `Page Name` keyboard; saved page additionally `Delete Page` | New default `Library Page`, icon Library, type both. 40-unit name input. Delete confirmation `Delete this page?` / `Your library media, watched state and playback progress are kept.` → Cancel/Delete; failure `Page not deleted` / `Retry after returning to the page.` |
| WIZ-002 / `2. Content Type` | `Movies`, `TV Shows`, `Both`, prefixed ✓ or ○ | Exactly one type, default Both. Draft only until Save Page |
| WIZ-003 / `3. Filters` | `Genres: All/<names>`, `Genre matching: Any/All`, `Year: All/<year>`, `Watched state: all/watched/unwatched/progress`, `Minimum rating: Any/<n>`, conditional `Original Language: All/<code>`, `Studio / Network: All/<name>` | Genres from snapshot, matching default Any. Year All then reverse numeric years. Watched choices `All`, `Watched`, `Unwatched`, `In Progress`; rating `Any`, `5`, `6`, `7`, `8`, `9`. Language excludes und/empty, localized display; studio values parsed. Facet absent if no available/selected value. Collection/icon serialized fields are **not** controls in this flow |
| WIZ-004 / `4. Display Options` | `View: grid/list` → `Display`: `Grid`, `List`; `Sort: title/year/added` → `Sort`: `Title`, `Year`, `Date Added`; `Direction: Ascending/Descending` | Default grid/title/ascending. Wizard sort options differ from full Library toolbar; no invented icon chooser |
| WIZ-005 / `5. Review` | Read-only Name, Content, Genres, Genre Match, Year, Watched State, Minimum Rating, Original Language, Studio / Network, Display, Sort + direction | `Live Preview` right panel: name, real summary from selected draft entries, up to 20 selected display names. Empty snapshot is meaningful, not made-up data |
| WIZ-006 / footer | If step>0 `Previous`; if step<4 `Next`, else `Save Page`; saved `Close Editor` or new `Cancel` | Exactly five steps. Saved background dimmed .35, API31 blur6; draft encoded separately. Validation `Review page settings`; `Enter a page name from 1 to 40 characters.`, `Choose Movies, TV Shows or Both.`, `Choose valid page filters and display options.`; failed commit `Page not saved` / `Keep editing and retry.` |
| WIZ-007 / dirty exit | `Unsaved Changes`; `You've made changes to your custom library page that haven't been saved. What would you like to do?`; `Continue Editing`, `Save Page`, `Discard Changes` | Discard callback navigates Home in current source; it is not assumed to invoke arbitrary requested leave. Saved close reverts draft. Filters custom toolbar remains ordinary filter dialog; Edit Library enters step0 |

Focus: rail focus changes active step; Left edge consumed, Right enters first option or footer; Up from first step allows TopNavigation. Centre Up/Down stays in options/footer, Left returns active step, Right enters preview scroll. Preview Up/Down scrolls72 scaled units, Left returns centre anchor, Right consumed. Back closes inline choice, then preview→centre, centre/footer→rail, rail→dirty exit. Save/Close restore `custom.control.edit`; stock/custom filters restore their respective opener via PreviewDialog. Restoration after Activity recreation captures draft/step/focus; runtime scroll proof remains UNKNOWN.
