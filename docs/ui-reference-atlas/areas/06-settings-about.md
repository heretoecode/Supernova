## Every-option records and bounds

[Declared preferences](../evidence/preferences-declared.tsv) includes exact English title, summary, array order/stored values/default/dependency/resource references for **130 declarations** (some category/key duplicates). [Effective preference map](../evidence/preferences-effective.tsv) applies verified moves/hiding/overrides and links consumer occurrences. It does **not** execute AndroidX preferences. Every conditional callback is traceable in display/focus source catalogue, including VideoPreferencesCommon's TV/API/advanced/sponsor/spatialization/passthrough/SMB/Trakt branches. Inherited API defaults/resource overlays absent from this checkout are marked external/unresolved; runtime option enablement/order and all localised language lists remain UNKNOWN where specified.

Do not equate a preference's old XML title or raw array with today's visible item. Example: full-scan/network-period preferences are constructed then hidden; Backup legacy resource titles still mention credentials, while current export summary and format exclude them. These discrepancies are documented, not repaired.
