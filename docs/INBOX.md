# Inbox — notes for Claude while Claude is unavailable

When Claude's usage has run out, leave new ideas, bugs or questions in either place:
- **Here:** on github.com, open this file on the branch `claude/supernova-github-access-yfhe89`, press the pencil,
  add a line, commit.
- **Or a GitHub issue** whose title starts with "Inbox:" (easiest from the GitHub phone app).

Another assistant can help word a note, but the owner pastes it in. **Claude reads this file at the start of every session**, moves each note
into the owner notes (or a GitHub issue), answers it, and clears it from here.

Keep it free of personal details (the repository may be public): no names, email, location, device names or
passwords.

## How to write a note
- One line per note, with the date: what you saw or want, and where in the app (page, button, title if it matters).
- Diagnostics: say the local time it happened, so Claude can find it in the report.
