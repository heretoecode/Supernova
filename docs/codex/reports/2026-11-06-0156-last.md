## 2. Unindexed-file online lookup

`metadata.UnlibraryLookup.start(context, fileUri, callbackExecutor, consumer)` returns a cancellable/closeable `Job`.
It parses just the filename with the actual MediaLib `SearchPreprocessor`, then calls the same validated read-only
TMDB search transport used by Fix match. A caller-owned HTTP-client overload of `StreamingRepository.matchSearch`
allows call cancellation and tighter timeouts while retaining endpoint/parameter allow-lists, response validation,
size bounds, authentication and diagnostic handling. The existing overload retains its original client.

Results expose kind, TMDB ID, title, year, season/episode, poster/backdrop URI and confidence. Episode identity is the
TMDB series ID plus parsed numbers. Artwork paths are constrained to TMDB image paths; credentials, request objects,
exceptions and original file locations are absent from results. A unique exact normalised title/year match is
confident; ambiguity or year mismatch remains possible. None/unknown is an ordinary immutable result.

The total deadline is twelve seconds, with two active/four queued jobs. Timeout/overload/offline/malformed/empty
results return NONE. Cancellation cancels the actual OkHttp call, interrupts the worker and suppresses callbacks
already queued to the caller's executor. A surviving job delivers at most once; executor delivery timing belongs to
the caller. No library insertion, database mutation or match application is invoked. Tests check parser queries,
episode identity, ambiguous/wrong-year matching, safe artwork, unchanged database inventory, actual caller-client
transport/allow-list use, callback executor ownership, timeout, active-call cancellation and queued-callback suppression.

The existing explicit one-file Add API is **MediaLib `VideoStore.requestIndexing(fileUri, context, false)`**.
It routes local files to Android's single-file scanner and other indexable URIs to existing provider/network paths.
The hooks explain the separate source-policy consent/persistence sequence (`BrowserSelection.include` and the existing
`ShortcutDbAdapter.VIDEO.applySupernovaRoots` transaction). A source refresh is not presented as the one-file API.
No screen is wired and no file is added merely by looking up its name.
