# TV-only removal map — read-only

Source: `72b0756cb` on claude/supernova-github-access-yfhe89. Supernova is Android TV only by owner decision. This map assumes the unsupported phone route and false-try_new_ui route will be removed; it does **not** mistake that future product boundary for current source unreachability. No code, manifest, resources or tests were changed.

## Boundary and prerequisite route cuts

1. EntryActivity.onCreate currently chooses MainActivity through UiChoiceDialog when leanback mode is false; MainActivityLeanback.onCreate also redirects to MainActivity. Remove those redirects and the legacy-UI launch action in MainFragment. Preserve original VIEW data/extras, playback/search/deep links and the BrowserActivityVideo alias pointing to EntryActivity; TV launcher integrations can still depend on that alias.
2. FoundationUiPolicy.apply forces try_new_ui=true for Foundation, but many shared helpers still read the preference. Replace UI selection branches with the TV-only policy before deleting their false branches. UiChoiceDialog also supplies mode constants and helpers used by player and ThemeManager; do not delete it wholesale while those references remain.
3. PlayerActivity.showVideoInfos still contains reflective TV-overlay routing and VideoInfoActivity fallback plus borrowed EXTRA_* constants. The modern read-only technical-info path is separate. Preserve the TV technical panel, transition/back behavior, intent extras and native metadata handling; move shared constants into a TV-neutral contract before deleting the phone Activity.
4. PlayerActivity MENU_PREFERENCES still explicitly names utils/VideoPreferencesActivity. Reroute that action to TV Settings with the same pause/return behavior before deleting the phone preferences host.
5. FileManagerService notification intents and AutoScraperActivity navigation also name MainActivity. Repoint retained TV service notifications to a supported TV entry. Removing phone Activity manifest entries alone leaves these broken.
6. Do not erase external contracts solely by their name: QueryBrowserActivityVideo has search intent filters, the legacy launcher alias is exported, and phone subtitle/preferences screens have exported entry points. Remove unsupported phone-specific contracts deliberately, and migrate any TV search/shortcut contract to the retained TV Activity/provider first.
