# 02 — Exhaustive current field and visibility inventory

All entries are S at signed 0.138. `P<n>` links the renderer; `M` means selected physical Movie/Video, `TV` local Tvshow, `E` physical Episode, `S` local season configuration, `R` remote-only movie/TV. An unmatched Video follows physical-file branch with no scraped identity. These are the real branches, not proposed labels. Source ledger E07–E15 and model excerpts reproduce them.

## Common rule for every lower fact

`fact(panel,label,value)` ([P348](https://github.com/heretoecode/Supernova/blob/b3504c2c4b1725f3070416d14b63e53ae1db3d74/src/main/java/com/archos/mediacenter/video/leanback/details/PreviewMoviePage.java#L348)) omits null or trim-empty values. It tests whitespace but does not trim the rendered value. A present row is non-clickable/non-focusable; its two TextViews are single-line, end-ellipsized. Newlines in the value become `, `; full `label: value` remains the row's contentDescription. No explicit char limit, hover/OK reader or marquee. The label uses 12sp/light/#B9C7D2; value 13sp/light/white; no localized label key (**literal English for every field here**). UI order is call order, not alphabetical. All panels are nonfocusable with `FOCUS_BLOCK_DESCENDANTS`. Android accessibility exploration is separate from D-pad; the descriptions exist but screen-reader behavior was not tested.

Cast and Crew wrappers disappear if their row lists are empty; Key Information remains even with no facts; Reception and Technical/Availability disappear if only their heading remains. Hidden columns redistribute available weight. Positive-number gates below mean zero/negative is **omitted**, never literal “Unknown,” except explicit Source/Location/Metadata fallbacks. No generic loading skeleton or “pending” lower fact is implemented.
